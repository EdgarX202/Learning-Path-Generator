# PathMind AI 🧠

[![Build](https://github.com/EdgarX202/Learning-Path-Generator/actions/workflows/main.yml/badge.svg)](https://github.com/EdgarX202/Learning-Path-Generator/actions/workflows/main.yml)
![GitHub License](https://img.shields.io/github/license/EdgarX202/Learning-Path-Generator)

An AI-driven Learning Path Generator (LPG) designed to create personalized study trajectories for tech students, integrated into a mock university portal.

---

## 🚀 Key Features
* **AI-Powered Recommendations:** Utilizes a local Llama 3 model via Ollama to generate context-aware learning paths.
* **University Portal Integration:** Built on top of a full-stack mock Edinburgh Napier University web interface.
* **Interactive UI:** Dynamic frontend for exploring custom courses, modules, and schedules.

---

## 🛠️ Tech Stack
* **Frontend:** React, HTML, CSS, JavaScript
* **Backend:** Python, Flask
* **AI Core:** Ollama (Llama 3 model)
